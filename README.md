# 오늘의 태그 ✦

하루를 기록하고 나의 패턴을 돌아보는 데일리 회고 웹앱

## 📌 프로젝트 소개

오늘의 태그는 복잡한 일기 작성 대신 간단한 태그 선택으로 하루를 기록하는 개인 회고 웹앱입니다.

사용자는 하루의 기분, 활동, 몸 상태, 자기 평가, 한 줄 메모를 기록할 수 있으며,
축적된 데이터를 기반으로 자신의 생활 패턴을 확인할 수 있습니다.

## ✨ 주요 기능

### 📝 오늘 기록
- 오늘의 기분 기록
- 오늘 한 활동 기록
- 몸 상태 기록
- 오늘의 나의 상태 기록
- 나를 칭찬할 점 기록
- 선택한 칭찬 항목별 짧은 메모 작성
- 한 줄 메모 작성
- 날짜를 선택해 과거 기록 작성 및 수정

### 📅 기록 히스토리
- 최근 7일 기록 확인
- 날짜별 상세 기록 조회
- 저장된 기록 불러오기
- 과거 날짜 기록 수정 및 삭제

### 📊 통계 대시보드
- 최근 7일 / 30일 기록 분석
- 기록한 날짜 및 기록률 확인
- 가장 많이 기록한 기분 확인
- 가장 많이 한 활동 확인
- 자주 느낀 몸 상태 확인
- 나를 칭찬한 횟수 확인
- 기분 변화 흐름 시각화

### 🌱 스마트 주간 회고
- 저장된 기록 데이터를 기반으로 자동 회고 제공
- 이번 주 기록 요약
- 잘한 점과 다음 주를 위한 제안 제공
